## 📖 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de criar um espaço profissional onde posso apresentar meus projetos, habilidades e conhecimentos em desenvolvimento web.

Além de funcionar como meu portfólio pessoal, o projeto também é utilizado como ambiente de aprendizado e prática, permitindo aplicar conceitos de desenvolvimento front-end, organização de código, responsividade e interação com JavaScript.

---

## 🚀 Tecnologias Utilizadas

O projeto utiliza atualmente:

* HTML5
* CSS3
* JavaScript
* Git
* GitHub

---

## ⚙️ Funcionalidades

* Interface responsiva para diferentes tamanhos de tela
* Navegação entre as seções do portfólio
* Apresentação de informações profissionais
* Seção para apresentação de projetos
* Formulário de contato
* Validação de formulário com JavaScript
* Animações e interações na interface

## 📂 Estrutura do Projeto

A estrutura do projeto foi organizada para manter uma separação clara entre páginas, estilos, scripts e recursos utilizados pela aplicação.

```text
portfolio/
│
├── assets/

│
├── css/
│
├── js/
│
├── index.html
│
├── .gitignore
│
└── README.md
```

> A estrutura poderá sofrer alterações conforme novas funcionalidades forem adicionadas ao projeto.

## 🛠️ Como Executar o Projeto

### 1. Clone o repositório

```bash
git clone https://github.com/kauemacedorocha013/Portf-lio-profissional..git 
```

### 2. Acesse a pasta do projeto

```bash
cd portfolio
```

### 3. Execute

Abra o arquivo `index.html` diretamente no navegador ou utilize uma extensão como o **Live Server** no Visual Studio Code.
